## Everything else

All gameplay code, procedural 3D models, canvas textures, interface, hip-hop beat, and sound effects are original works created for Hippity Hop. No CC0 or stock art files are bundled because the visuals and audio are generated in code. System fonts only (Impact, Arial Black, and similar). No copyrighted music.

## Build

From `hippity-hop-src/`:

```
npm install
npm run build
```

The static site is written to `hippity-hop/` and is what GitHub Pages serves.
